# Arham Kelkar — Portfolio

A responsive, dark editorial portfolio for Arham Kelkar, focused on AI, machine learning and GenAI.

## Run locally
This is a static HTML/CSS/JavaScript site. Open `index.html` in a browser or serve the folder with any static web server.

## Before publishing
- Add real hackathon/event photos to the recognition gallery.
- Replace project profile links with the exact repository URLs and add demos where available.
- Confirm achievement wording and dates.
- Confirm the public resume PDF is current.

## Deploy
The site is compatible with Vercel static deployment. The root directory is the project root; no build command is required.
